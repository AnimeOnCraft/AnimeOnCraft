# Детальные лисьи ушки — первый образец

Редактируемый проект Blockbench: fox-ears.bbmodel. Проверено открытие в установленном Blockbench 5.2.2. Это настоящая полигональная модель с текстурой, а не изображение концепта.

- Три сетки аксессуара: два заострённых уха с фасками и вставками, изогнутый ободок.
- 106 граней, из них 26 треугольников; текстура 128×128.
- Две грани внутренних вставок используют полную яркость в игре. Динамическое освещение мира и частицы не создаются.
- Серый блок REFERENCE_HEAD_not_exported — ориентир для головы 8×8×8; в игровой экспорт он не входит.
- Начало координат проекта — верх головы. Экспорт переводит его в координаты слоя головы Minecraft.

Открыть редактор с профилем, кэшем и временными файлами на F:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File F:\AnimeOnCraft\scripts\open-cosmetic-model.ps1
```

Обычные изменения проекта сохранять в этот же .bbmodel, текстуру — в fox-ears.png. Для пересборки игрового экспорта из корня F:\AnimeOnCraft:

```powershell
node scripts/export-beta-cosmetics.mjs
```

Экспорт читает треугольные/четырёхугольные сетки .bbmodel и обновляет cosmetics/fox_ears.json и textures/cosmetics/fox_ears.png в ресурсах собственного мода. Геометрия ограничена 512 гранями, координаты и UV проверяются. Для проверки изменений геометрии перезапустить тестовый клиент.

create-fox-ears-model.mjs создаёт исходную заготовку и по умолчанию отказывается перезаписывать существующий проект. Его --regenerate заменяет проект: не использовать после ручных правок.

Игровой просмотр после подготовки локального комплекта:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File F:\AnimeOnCraft\scripts\preview-detailed-cosmetics.ps1
```

Образец ушек сохранён в полном локальном комплекте восьми детальных моделей и общего слота спины. См. minecraft/cosmetics/README.md и docs/operations/COSMETICS_WARDROBE_LOCAL_2026_10_23.md. Файл cosmetic.json хранить рядом с проектом: редактор может удалить нестандартные поля внутри .bbmodel. Публикация не выполняется.
