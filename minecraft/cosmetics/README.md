# Косметика бета-пасса — проекты Blockbench

Все восемь предметных наград имеют редактируемый `.bbmodel`, текстуру 128×128 и `cosmetic.json`. Два титула остаются текстовыми эффектами, их иконки сохранены.

| Проект | Предмет | Геометрия |
| --- | --- | --- |
| fox-ears | Ушки лисы | Фаски, ободок, светящиеся вставки; утверждённый образец сохранён |
| oni-mask | Маска они | Изогнутая маска, клыки, крепления |
| cyan-visor | Неоновый визор | Изогнутая линза, оправа и дужки |
| shard-crown | Осколочная корона | Обод и пять парящих гранёных кристаллов |
| orbit-halo | Орбита | Вращающееся кольцо с тремя кристаллами |
| rift-lantern | Фонарь Разлома | Цепь, каркас и светящийся кристалл |
| star-chain | Звёздная цепь | Отдельные звенья и качающийся звёздный подвес |
| rift-mantle | Мантия Разлома | Наплечная часть, застёжки и четыре отдельных полотна с рунами |

Открыть нужный проект, например мантию:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File F:\AnimeOnCraft\scripts\open-cosmetic-model.ps1 -Model rift-mantle
```

Редактор F:\BlockBench\Blockbench.exe запускается с отдельным профилем F:\AnimeOnCraft\.tools\blockbench-profile, TEMP/TMP на F:. Сохранять правки в существующий проект и его PNG. Файл **cosmetic.json обязательно оставлять рядом**: он задаёт слот привязки, светящиеся участки атласа и оси анимации; Blockbench не сохраняет произвольные поля проекта. Имена подвижных сеток начинаются с `part_id__`, например `panel_0__`.

После сохранения:

```powershell
cd F:\AnimeOnCraft
node scripts/export-beta-cosmetics.mjs --model=rift-mantle
```

Без `--model` экспортируются все проекты. `export.json` содержит SHA256 исходника, число граней и пути игрового JSON/PNG. Сетка REFERENCE имеет export=false и не попадает в игру. Экспорт проверяет текстуру, UV, нормали и предел 512 граней на предмет. `.bbmodel` и экспорт соответствуют друг другу; отдельная ручная копия геометрии не поддерживается.

`create-beta-accessory-models.mjs` — генератор исходных заготовок. По умолчанию не перезаписывает проекты. `--regenerate` использовать только для осознанного возврата к заготовке; ручные правки он заменяет. Ушки имеют отдельный генератор `create-fox-ears-model.mjs`.

Анимация выполняется в собственном слое игрока: кольцо вращается, кристаллы слегка парят, подвесы качаются, полотна мантии реагируют на движение и приседание. Светящиеся вставки имеют отдельный проход с проверкой глубины, без динамического света, частиц и сущностей. Невидимые игроки и наблюдатели скрывают аксессуары; элитры скрывают мантию. При перезагрузке ресурсов сетки перечитываются. При повреждённом ресурсе предмет пропускается с предупреждением в журнале.

Это локальная разработка. Установщик и публичный модпак автоматически не меняются.
