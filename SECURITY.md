# Проверка безопасности

Обнаружив уязвимость, не публикуйте пароли, ключи, данные игроков или работающий
способ доступа к чужому аккаунту в открытой задаче. Используйте вкладку Security →
Report a vulnerability, если она доступна. При её недоступности создайте задачу без
технических подробностей с просьбой о приватном контакте с владельцем.

Исходный код делает поведение доступным для проверки; это не гарантия безопасности
любого EXE. Код текущей ветки разработки может отличаться от уже выпущенного файла.
Сверяйте версию, контрольную сумму и подпись конкретного установщика.

Что проверять:

- apps/launcher/src-tauri/src/simple_update.rs — скачивание обновлений и проверка подписи;
- apps/launcher/src-tauri/src/game_launch.rs — подготовка и запуск Java/Minecraft;
- apps/launcher/src-tauri/src/credential_store.rs — локальное хранение авторизации;
- apps/launcher/src-tauri/src/public_api.rs — разрешённые адреса API;
- minecraft/modpack/profile.json — источники, версии и SHA256 модов;
- scripts/build-launcher-installer.ps1 — сборка установщика;
- apps/backend/src/modules/auth — пароли, сессии, допуск и серверная авторизация.

В публичный репозиторий не входят .env, закрытые ключи, рабочие базы, миры,
персональные журналы и резервные копии. Для собственного развёртывания создавайте
свои секреты. Открытый ключ проверки обновлений является публичным по назначению.
Собственная сборка не получает доступ к аккаунтам или ключу подписи владельца.
