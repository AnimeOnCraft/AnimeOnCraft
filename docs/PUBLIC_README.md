# AnimeOnCraft

Открытый код лаунчера, API и собственного игрового мода AnimeOnCraft.

[Скачать официальный лаунчер](https://animeoncraft.github.io/) ·
[Сборка из исходников](docs/BUILD_FROM_SOURCE.md) ·
[Проверка безопасности](SECURITY.md) · [Участие](CONTRIBUTING.md)

## Что здесь находится

| Каталог | Назначение |
| --- | --- |
| apps/launcher | Интерфейс React и нативная часть Tauri/Rust: обновления, аккаунт, установка и запуск игры |
| apps/backend | NestJS API, авторизация, кланы, гардероб и миграции PostgreSQL |
| apps/admin | Веб-интерфейс управления |
| apps/download-site | Статический сайт скачивания |
| minecraft/integration | Собственный мод NeoForge 1.21.1: допуск, территории, захват, косметика и игровое меню |
| minecraft/modpack | Профиль сторонних модов с версиями, источниками и контрольными суммами |
| minecraft/server | Конфигурация мира и баланса |
| packages | Общие контракты и элементы интерфейса |
| scripts, infra | Сборка, локальные проверки и инфраструктурные шаблоны |

Собственный код доступен по **MIT**. Художественные материалы и зависимости имеют
отдельные условия — [NOTICE.md](NOTICE.md). Minecraft и JAR-файлы сторонних модов
не публикуются в этом репозитории.

## Как проверить

Исходники позволяют изучить сетевые запросы, работу с авторизацией, обновление
и запуск Java. В [SECURITY.md](SECURITY.md) указаны основные файлы для проверки.
Можно самостоятельно собрать лаунчер по [инструкции](docs/BUILD_FROM_SOURCE.md).

Тег `v0.8.10` содержит исходники выпуска 0.8.10. Контрольные суммы установщика,
игрового мода и профиля модпака записаны в `RELEASE_BUILD.json`. Побитовое
совпадение самостоятельной сборки не гарантируется. Публичная история
начинается с очищенного снимка: закрытые ключи, рабочие .env, аккаунты, базы,
миры, журналы и служебная история сюда не входят. Перечень и SHA256 файлов
снимка находятся в SOURCE_SNAPSHOT.json.

Открытый код сам по себе не гарантирует безопасность произвольного EXE.
Скачивайте официальный файл с сайта и сверяйте конкретную версию и подпись.

## Текущее развитие

В игровой гардероб добавлены эмоции: один стартовый танец и две позы.
Владение хранится в аккаунте и проверяется сервером. Будущие косметические
награды можно выдавать через тот же механизм; платёжного магазина пока нет.
Новые игровые возможности сначала проверяются локально и выпускаются отдельно.
