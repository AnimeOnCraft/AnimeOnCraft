# Участие в разработке

Обсуждения, отчёты об ошибках и pull request принимаются в
https://github.com/AnimeOnCraft/AnimeOnCraft. Укажите версию лаунчера, шаги
воспроизведения и обезличенный фрагмент журнала. Удаляйте токены, адреса почты
и прочие личные данные перед публикацией.

Собственный код вносится под MIT. Проверяйте соответствующий модуль:
TypeScript — typecheck и тесты; Rust — cargo test; игровой мод — Gradle test и jar.
Новые миграции добавляются отдельными файлами. Не меняйте старые миграции,
чужие данные, версии публичного обновления и рабочий мир в обычном исправлении.
Для игровых проверок используйте отдельные каталоги, порты и тестовые аккаунты.

Публичный репозиторий начинается с очищенного снимка разработки. Служебная история
не включена. Публикация исходников не является выпуском установщика.
