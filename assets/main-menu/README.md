# Главное меню

`source.mp4` — ролик IMG_1131.MP4, предоставленный владельцем 25.10.2026
для главного меню Minecraft. Логотип уже находится в изображении.
Материал сохраняет отдельные права согласно NOTICE.md.

`node scripts/upscale-title-menu.mjs` извлекает исходные кадры без JPEG-потерь
и обрабатывает их Real-ESRGAN `realesr-animevideov3` ×2 (2560×1440).
Портативная программа и модели лежат на F: в `.tools/main-menu-upscale-20261025/tool`;
можно задать REALESRGAN_PATH/REALESRGAN_MODELS. Источник программы —
https://github.com/xinntao/Real-ESRGAN/releases/tag/v0.2.5.0 (BSD-3-Clause).

Затем `node scripts/prepare-title-menu-assets.mjs` из улучшенных PNG готовит 238
кадров JPEG 1920×1080, 24 кадра/с, q2/4:4:4 и OGG из звука ролика.
Предыдущие пережатые JPEG не используются. Хеш исходного ролика проверяется по
provenance.json. Другой каталог кадров задаётся AOC_TITLE_UPSCALED_FRAMES,
FFmpeg — FFMPEG_PATH. Все большие промежуточные файлы остаются на F:.

Нейросеть и FFmpeg работают только при подготовке материалов;
в игре — штатные LWJGL STB, динамические текстуры и музыкальный менеджер.
Качество не снижать снова ради ограничения размера старого установщика:
при публичном выпуске отдельно решить доставку HD-материалов.
