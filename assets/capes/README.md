# Плащ Beta

Дизайн основан на присланном владельцем изображении: чёрно-фиолетовая ткань, ступенчатая светящаяся рамка, вертикальная надпись `beta` и звёзды. Изображение создано встроенным imagegen; новый API-ключ не использовался. Исходная генерация сохранена как `beta-source.png`.

Сводка запроса генерации: плоская прямоугольная панель5:8 без персонажа/перспективы/складок; чёткий pixel art, почти чёрный фиолетовый центр, чёрные полосы по краям, яркая симметричная ступенчатая рамка, редкие фиолетовые искры; четырёхлучевые звёзды сверху/снизу и точные строчные готические буквы b/e/t/a друг под другом с розово-белым свечением. Присланная картинка служила визуальным образцом.

`scripts/pack-beta-cape.mjs` выполняет техническую упаковку в Minecraft UV: atlas1024×512 (64×32 с масштабом16), лицевая/обратная панель160×256 и тёмные боковины. Он создаёт `beta-preview.png`, launcher preview и `minecraft/integration/neoforge/src/main/resources/assets/animeoncraft/textures/capes/beta.png`. Повторная техническая упаковка не вызывает imagegen.

Реальная проверка Minecraft: `.tools/beta-cape-minecraft.png`; надпись ориентирована правильно, видны рамка и звёзды. Камера/снимок acceptance включаются только специальным JVM-свойством, UUID тестового игрока и портом25566. Обычный игрок не получает смену камеры или автоматические снимки.

## Персональные плащи

Первый персональный плащ: `ayaa-cobblestone`, «Булыжник · Ayaa». Получатели по прямому запросу: игрок Ayaa и действующий владелец Y2K; следующие плащи также выдавать владельцу. Создан встроенным image_gen по фотографии `F:/ScreenShots/photo_2026-10-19_12-31-41.jpg`, без CLI/API-ключа.

Промпт генерации: плоская панель 5:8 без персонажа, перспективы, складок и полей; Minecraft pixel art, тёмная сине-фиолетовая ткань, яркая пурпурная рамка/вспышка, центральный серый куб булыжника, розовые сердца, золотые звёзды и короны. Точные строки сверху вниз: `hentai` (розовый), `пупсик` (золотой), `ТОП 1` (белый), куб, `малыш` (розовый), `няшка` (голубой), `камень` (белый), `булыжник` (золотой). Изображение служит только образцом рисунка; никаких новых надписей или символов.

Файлы: `ayaa-cobblestone-source.png` — исходная генерация; `ayaa-cobblestone-preview.png` — панель 160×256; `ayaa-cobblestone-texture.png` — Minecraft UV 1024×512. Техническая упаковка: `node scripts/pack-personal-cape.mjs ayaa-cobblestone`; она не перерисовывает исходник.

`catalog.json` — каталог, который читают API и игровой сервер. Для следующего плаща добавить отдельную запись и PNG; пересборка клиента для каждого следующего рисунка не нужна после первого выпуска с персональным гардеробом. Имя ID: строчные латинские буквы, цифры и дефис, до32 символов; пути только внутри этой папки.

Выдача: `node scripts/grant-player-cape.mjs CAPE_ID GAME_NICK` — проверка получателей; добавить `--apply` для выдачи с аудитом. Команда находит именно игровой ник, включает действующего владельца, не меняет надетый плащ и не создаёт дубли. Перед первой выдачей персонального ID применить миграцию `20261019000100_personal_capes` и обновлённый API: старый API считает все записи Beta и сломал бы старый лаунчер при выдаче второго плаща.

### Сова · TrickyOwl

Второй плащ `trickyowl-owl` подготовлен для TrickyOwl и владельца Y2K; выдача ждёт общего пакета. Образец: `F:/ScreenShots/photo_2026-10-19_16-20-25.jpg`. Встроенный image_gen: плоская панель5:8 без персонажа/перспективы/полей; коричневая ушастая сова с усталыми янтарными глазами, тёмным клювом, детальными перьями, лапой у клюва и зажжённой сигаретой слева; серый дым вверх по левой стороне, почти чёрный коричневый фон, Minecraft pixel art, без текста/новых элементов. Исходник `trickyowl-owl-source.png`, панель `trickyowl-owl-preview.png`, UV `trickyowl-owl-texture.png`; для боковин задан тёмно-коричневый edge_rgb. Технический упаковщик сохраняет прежние боковины для существующих плащей по умолчанию.

Очередь выдачи: `pending-grants.json`; проверка всех панелей/UV/размеров сетевого пакета: `.tools/verify-pending-cape-assets.mjs`, receipt `.tools/pending-cape-assets-result.json`. На сервер/аккаунты второй плащ не переносился; новую сборку лаунчера ради новой картинки делать не требуется.
